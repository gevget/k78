# K78 — static website preview

This repository publishes the K78 dental clinic website preview to GitHub Pages.

- Site: https://gevget.github.io/k78/
- Pages source: `site/`
- Deployment: GitHub Actions on pushes to `main`
- The pages keep `noindex,nofollow` and are a static preview. They do not run WordPress, PHP, the CMS admin, forms, CRM, or online booking.
- Clinic facts, prices, doctor information, reviews, and media still require the clinic's final review before production use.

GitHub Pages only serves static files. Use the separate WordPress hosting plan for the production CMS.
